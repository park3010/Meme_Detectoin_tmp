\section{Problem Formulation}
\label{sec:problem}

\subsection{Structured Harmful Meme Interpretation}
\label{sec:problem:task}

A meme is a multimodal instance
$\mathcal{M}=(I,T)$, where $I$ denotes the meme image and
$T$ denotes the text extracted from the image using optical
character recognition.
Conventional harmful meme detection typically maps
$\mathcal{M}$ to a binary harmfulness label.
We instead formulate harmful meme understanding as a
\emph{structured interpretation} problem that jointly identifies
whether the meme is harmful, whether and how a target is expressed,
what primary communicative intent it conveys, which rhetorical
strategies it employs, and how the image and text interact to
construct its meaning.

For each meme, the model predicts

\begin{equation}
\hat{\mathcal{Y}}
=
\left(
\hat{y}^{h},
\hat{y}^{p},
\hat{y}^{g},
\hat{y}^{i},
\hat{\mathbf{y}}^{r},
\hat{y}^{m}
\right),
\label{eq:structured_output}
\end{equation}

where $\hat{y}^{h}$ is the harmfulness prediction,
$\hat{y}^{p}$ denotes target presence,
$\hat{y}^{g}$ denotes target granularity,
$\hat{y}^{i}$ denotes primary communicative intent,
$\hat{\mathbf{y}}^{r}$ is a multi-label prediction over rhetorical
tactics, and $\hat{y}^{m}$ denotes the multimodal relation through
which the image and text jointly convey meaning.

Harmfulness, target presence, target granularity, primary intent,
and multimodal relation are formulated as single-label
classification tasks.
Rhetorical tactic prediction is multi-label because a meme may
simultaneously employ several strategies, such as sarcasm,
stereotyping, dehumanization, or exaggeration.
Labels marked as unknown, ambiguous, ignored, or otherwise invalid
under the canonical annotation policy are excluded through
field-level supervision masks rather than being interpreted as
negative examples.
A valid \texttt{none} label remains a legitimate class or
multi-label state when the annotation schema explicitly defines the
corresponding phenomenon as absent.

\subsection{Evidence-Grounded Interpretation}
\label{sec:problem:evidence}

Structured predictions alone do not indicate which observations or
contextual information support the interpretation.
We therefore associate each prediction with an explicit evidence
record.

Let

\begin{equation}
\mathcal{E}^{\mathrm{int}}
=
\left\{
\mathcal{E}^{\mathrm{global}},
\mathcal{E}^{\mathrm{local}},
\mathcal{E}^{\mathrm{text}},
\mathcal{E}^{\mathrm{cross}}
\right\}
\label{eq:internal_evidence}
\end{equation}

denote evidence extracted directly from the meme.
These components represent global visual information, localized
objects or symbolic regions, OCR-derived textual evidence, and
cross-modal cues arising from the interaction between image and
text.
They are considered \emph{internal} because they are derived from
the observed meme rather than from an external knowledge source.

Some memes additionally require contextual information that is not
explicitly present in the image or OCR text.
The framework may therefore acquire a candidate knowledge set

\begin{equation}
\mathcal{K}^{\mathrm{cand}}
=
\left\{
k_1,\ldots,k_K
\right\},
\label{eq:knowledge_candidates}
\end{equation}

through retrieval, context generation, or predefined fallback
mechanisms.
Candidate acquisition does not imply evidential validity:
retrieved material may be only weakly relevant, while generated
context may contain unsupported hypotheses.

We therefore define a verification procedure

\begin{equation}
\mathcal{K}^{\mathrm{ver}}
=
\mathcal{V}
\left(
\mathcal{M},
\mathcal{E}^{\mathrm{int}},
\mathcal{K}^{\mathrm{cand}}
\right)
\subseteq
\mathcal{K}^{\mathrm{cand}},
\label{eq:verified_evidence}
\end{equation}

where $\mathcal{V}$ evaluates candidate relevance, validity, and
task-specific support.
The candidate state is retained throughout this process:
retrieved documents, generated hypotheses, fallback candidates,
verified evidence, and rejected candidates remain distinguishable
through provenance metadata.

The final prediction is accompanied by an explanatory record

\begin{equation}
\hat{\mathcal{A}}
=
\left(
\hat{\mathcal{A}}^{\mathrm{int}},
\hat{\mathcal{A}}^{\mathrm{ext}},
\mathcal{P},
\hat{R}
\right),
\label{eq:explanation_output}
\end{equation}

where

\begin{equation}
\hat{\mathcal{A}}^{\mathrm{int}}
\subseteq
\mathcal{E}^{\mathrm{int}},
\qquad
\hat{\mathcal{A}}^{\mathrm{ext}}
\subseteq
\mathcal{K}^{\mathrm{ver}}
\end{equation}

are the internal and external evidence items selected for
attribution, $\mathcal{P}$ denotes their provenance and processing
history, and $\hat{R}$ is a concise rationale conditioned on the
structured prediction and selected evidence.
The rationale is an inspectable explanatory output rather than a
replacement for the formal task predictions, and it should not
introduce claims unsupported by either the observed meme or
verified contextual evidence.

\subsection{Masked Multi-Task Learning Objective}
\label{sec:problem:objective}

Let
$\mathcal{Q}=\{h,p,g,i,r,m\}$ denote the six formal prediction
tasks.
For sample $n$ and task $q$, let
$m_n^q\in\{0,1\}$ indicate whether valid supervision is available
for that field.
Let $w_n$ denote the sample weight determined by the normalized
annotation-quality policy, and let $\lambda_q$ denote the weight
assigned to task $q$.

The masked multi-task objective is

\begin{equation}
\mathcal{L}(\theta)
=
\frac{1}{N}
\sum_{n=1}^{N}
w_n
\sum_{q\in\mathcal{Q}}
\lambda_q m_n^q
\,
\ell_q
\left(
f_\theta^q(\mathcal{M}_n),
y_n^q
\right),
\label{eq:multitask_objective}
\end{equation}

where $f_\theta^q$ denotes the trainable prediction function for
task $q$.
We use single-label classification losses for
$q\in\{h,p,g,i,m\}$ and a multi-label binary classification loss
for $q=r$.
The masks allow partially annotated samples to contribute to tasks
for which valid supervision exists without converting missing,
unknown, ambiguous, or ignored labels into negative examples.

The objective supervises the formal structured outputs rather than
the generated rationale.
Evidence provenance, verifier metadata, gating states, and rationale
text are retained for attribution and diagnostic analysis unless
explicitly specified otherwise by an experimental condition.

\subsection{Cross-Dataset Generalization}
\label{sec:problem:generalization}

We study source-to-target generalization under a locked
development protocol.
Let

\begin{equation}
\mathcal{D}_{S}
=
\mathcal{D}_{\mathrm{COVID}}
\cup
\mathcal{D}_{\mathrm{Politics}}
\end{equation}

denote the retained HarMeme source collection after the source-level
integrity procedure described in
Section~\ref{sec:setup:datasets}.
The two domains preserve their original identities while sharing a
common structured label space.
The source collection is partitioned into an immutable training set
$\mathcal{D}_{S}^{\mathrm{train}}$ and validation set
$\mathcal{D}_{S}^{\mathrm{val}}$.
The Facebook Hateful Memes benchmark forms a disjoint held-out
target set $\mathcal{D}_{T}$.

For a trainable model, parameters are optimized only using the
source training partition:

\begin{equation}
\theta^{*}
=
\arg\min_{\theta}
\mathcal{L}
\left(
\theta;
\mathcal{D}_{S}^{\mathrm{train}}
\right).
\label{eq:source_training}
\end{equation}

All development decisions are restricted to source data.
These include early stopping, checkpoint and hyperparameter
selection, calibration or decoding-threshold selection, prompt
development, few-shot demonstration selection, retrieval-profile
construction, and knowledge-source configuration.
Let $\tau^{*}$ denote the resulting fixed decoding policy.
Held-out prediction is performed only after the model and decoding
configuration have been frozen:

\begin{equation}
\hat{\mathcal{Y}}_{T}
=
f_{\theta^{*},\tau^{*}}
\left(
\mathcal{D}_{T}
\right).
\label{eq:heldout_evaluation}
\end{equation}

No target-domain example is used to train or select the model,
construct retrieval resources, develop prompts, determine decoding
rules, or choose among experimental configurations.
For retrieval-based conditions, the active knowledge index is
restricted to permitted HarMeme training origins.
This protocol evaluates whether harmfulness detection, structured
interpretation, and evidence-grounded reasoning learned from the
source domains transfer to an unseen meme distribution.
