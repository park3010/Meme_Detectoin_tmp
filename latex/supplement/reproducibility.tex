\section{Reproducibility and Artifact Audit}
\label{sec:supp:reproducibility}

Every run records the requested command, resolved configuration, environment,
source and evaluation manifests, predictions, thresholds, metrics, runtime,
checkpoint checksums, and a pipeline audit.  Paper export additionally
requires strict artifact and leakage audits, the complete registered seed set,
matching protocol/manifests, a non-smoke suite, and a paper-eligible formal
metric.  Smoke and pilot suites remain visible for QA but cannot populate
paper tables or result macros.  Source-tree hashes are recorded per run;
external adapters additionally bind the official repository commit and local
patch provenance.  This per-run policy is necessary because pilot repairs can
have distinct source hashes and must not be silently mixed into final
multi-seed comparisons.

Storage preflight resolves the filesystem backing each output root and checks
conservative checkpoint plus temporary-write headroom before training.
Checkpoints are written to a temporary file in the destination directory,
flushed and checked for nonzero size, then installed with an atomic rename.
Run failure prevents completion status and retains a failure manifest when
possible.  Runtime instrumentation uses synchronized monotonic phase timers
and CUDA peak-memory counters; unavailable historical measurements remain
null rather than estimated.
